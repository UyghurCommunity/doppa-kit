# Contributing / تۆھپە قوشۇش

Bug reports, documentation, accessibility feedback and Uyghur language corrections are welcome.

1. Open an issue describing the problem or proposed change.
2. Run `npm test` and serve the demo over HTTP.
3. Include a focused regression test for behavior changes and a screenshot for visual changes.
4. Describe whether artwork is an original interpretation or based on a specific documented source; do not invent traditional meanings.

Do not submit font files, copyrighted source assets or private information without clear permission. Code contributions use the repository MIT license.
